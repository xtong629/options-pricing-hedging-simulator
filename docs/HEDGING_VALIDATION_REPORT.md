# Phase 3 对冲验证报告

## 设计与复现

以 P 测度 GBM 模拟股票，漂移为 μ−q；期权价值与 Delta 采用 Q 测度的 BSM，利率 r 与 μ 分开。
初始收到一份空头 Call 权利金并买入 mΔ 股。股票交易以成交额乘 bps 计费，现金按连续复利计息，
左端股票价值近似股息，每个基础日入账。到期清仓并支付 payoff，最终现金为 P&L。
股息网格细分时保持原有交易时点不变。

复现命令 `python examples/hedging_research.py`，输出 /tmp/phase3_hedging_arrays.npz 和
/tmp/phase3_hedging_summary.json。数组含各路径 P&L、成交额、费用、成交数及费用终值影响，
可重算下表。费用为零的 P&L 即毛对冲误差；含费 P&L 为净值。样本标准差采用 n−1。

参数 S=K=100、T=1、乘数 100、r=.03、q=0、μ=.05、隐含波动率 .20；
每个路径波动率使用 10,000 条 P 路径，PCG64 种子 20261122，批次 512。
每批日/周及费用情景共用价格路径。完整元数据和汇总见 [JSON](results/phase3_hedging_summary.json)。

## 手算账本与股息验证

测试采用路径 100→110→90、半年间隔、q=.01、r=.03、10 bps、乘数 100。
初始权利金 882.732123，买入 57.349598 股，费用 5.734960，现金 −4857.962628，权益 −5.734960。
半年融资 −73.418703、股息 28.674799，调仓买入 21.511968 股并付费 2.366316。
到期股息 43.373861，清仓 78.861566 股、付费 7.097541，payoff 为零，终值现金 −247.465048。
测试独立逐项重建现金并按市值变动、负债重估、利息、股息及费用核对权益。另有价内结算案例。

固定持仓确定性股息积分在 252/504/1008 步的绝对误差分别为
0.00323867、0.00161936、0.00080969，小于最后网格 0.1 的计划门槛。
耦合随机路径的相邻网格 P&L 差 RMSE 分别为 0.07212、0.03739；测试也验证累计股息差 RMSE 下降、
共享调仓时点价格相同及成交次数相同。此为离散近似的有限样本验证。
