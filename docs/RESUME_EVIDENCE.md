# 公开证据台账

当前成果为 Phase 0 的业务、架构、验收与开发设计。此阶段可以描述已设计空头欧式看涨期权的自融资账本和独立验证方案。应用实现、测试通过数、实验规模、误差、性能、对冲效果与发布记录均待对应阶段验证。规划输入不能作为运行结果。

|待验证能力|预期代码与测试定位（拟建）|需附的公开证据|状态|
|---|---|---|---|
|解析定价和敏感度|pricing、greeks；积分/差分测试|数学验证报告，最大绝对误差及对应参数|待实施|
|随机估值|simulation；对偶对和种子回归|收敛图，实际路径数、独立样本数、SE 与覆盖率|待实施|
|自融资复制|portfolio、hedging；逐笔对账|可重放账本、结算差额、同路径频率比较|待实施|
|风险及交易成本|risk、pnl；手算尾损与费用测试|分布、归因、成本敏感度报告及配对区间|待实施|
|可复现交付|experiments、reporting、CLI 与 CI|运行记录、安装验证、性能基准及 release 链接|待实施|

每条实绩记录填写：能力描述、合并 SHA/PR、模块和测试永久链接、命令、配置与种子、实际规模、硬件与版本、误差/耗时及单位、结果文件、CI 日志、限制和审核日期。简历表述只能从审核后的记录提取，并限定模型、样本和比较基准。当前不能声称实盘执行、银行业绩、性能提升或策略收益。
