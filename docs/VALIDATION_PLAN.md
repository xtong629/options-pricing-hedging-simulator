# 验证矩阵与实验协议

每次报告保存 git SHA、配置、依赖版本、浮点类型、种子、位生成器、批大小和输出摘要。以下规模和阈值均为拟定验收条件。修改公差须说明数值原因并保留失败样例。

|模块|独立检查与门槛|
|---|---|
|解析定价|以 SciPy quadrature 积分折现的对数正态 payoff，在执行价处分段。常规网格误差 ≤1e−8 × max(1,S,K)；另验 C−P=A−B、无套利上下界、执行价单调性、到期及确定性极限。拒绝 NaN、无穷、非法期限与类型|
|Greeks|独立中心差分，Gamma 用二阶差分，Theta 对剩余期限差分取负；保持其余参数固定。用相对 bump 1e−3、1e−4、1e−5 比较截断与舍入区间，常规点目标 abs(error) ≤1e−6 + 1e−4 abs(reference)。避开不可导点，单独断言边界状态|
|GBM|对数增量均值和方差对照解析矩，零路径波动率退化至确定性远期；同配置重放，P/Q 漂移参数隔离|
|MC|终值直接采样并折现。普通抽样以每条 payoff 为独立观测；对偶抽样以同一 Z 和 −Z 的两条折现 payoff 的均值为一个观测，拒绝奇数路径。SE=s/√n，s 取独立观测样本标准差；95% 区间用均值 ±1.96 SE，注明渐近近似。常规固定种子样例要求误差 ≤4 SE 加数值公差；零方差单独对照确定性值。多种子研究比较经验 RMSE 与 N 的 −1/2 斜率、覆盖率及二项抽样误差，不要求每次落在 95% 区间|
|账本|手算双步涨跌、平价到期、负现金、非零股息与最后不足五步情景。逐笔检查 H'=H+u，时点权益变化等于负费用；初始权益为负建仓费；到期头寸归零，现金重建误差 ≤1e−10 × max(1,累计绝对现金流)。改变路径后缀须保持此前决策逐项一致|
|成本|成交次数仅计非零股数，turnover 为 Σ abs(u)S（币种成交额），名义成本为 c×turnover。固定路径和交易规则时，无费与有费终值差应等于每笔费用累积到到期的和；总成本表只汇报实际名义支出|
|风险|误差定义为零成本复制目标下的终值净 P&L，相对于目标零；分别列毛误差与含费净值。RMSE=√mean(P&L²)，标准差用 n−1。损失 L=−P&L；VaRα 取升序第 ceil(nα) 项，ES 取最差 (1−α)n 个样本的均值，边界按分数权重。样例损失 [−2,0,1,5]，α=.625 时 VaR=1、ES=11/3；另验全相同、重复值、小样本、空数组与非法 α|
|归因|每段用左端 Greeks，股票和期权合计方向项 (H−mΔ)ΔS，期权另计 −m[Γ(ΔS)²/2+Θh+Vega Δσ]。独列利息、股息、费用，期初建仓费计入；残差=实际权益变化减分项和。到期以 payoff 作最终 mark。检查逐段及全期对账；冲击较大、临近到期、交叉项均可放大残差，常数隐含波动率下 Vega 项为零|

## 两种运行模式

Fast 使用固定种子、4 个 call/put 常规配置，每配置 4,096 条终值路径，对冲 256 条一年路径。CI 运行解析、统计和账本不变量；少量尾部样本仅检查定义。Full 采用 call/put × K/S∈{0.9,1,1.1} × T∈{0.25,1} × σ∈{0.15,0.30} 共 24 组，每组 100,000 条终值路径（对偶为 50,000 个独立对）。收敛研究选平值配置，以独立种子重复 100 次，比较 1k、10k、100k 路径，与同预算普通抽样比较。统一 S=100、r=.03、q=.01，股息另设零值基准。

对冲主实验取一年平值 call，m=100、q=0、μ=.05、隐含波动率 .20；路径波动率 .15/.20/.30、日/周调仓、成本 0/1/5/10 bps，同种子共享基础冲击。每种波动率 10,000 条独立 P 路径。报告净损益均值、波动、RMSE、95% VaR/ES、成交额与成本；对日周差值按路径 ID 配对 bootstrap（固定独立种子）估计区间。以固定路径追加 spot/隐含波动率冲击重估，分开报告静态风险与动态 P&L。

终值估计按批（如 4,096 条）更新均值和二阶矩。10,000×253 的单张 float64 路径矩阵约 19.3 MiB，策略与情景复制会倍增；对冲按 512 条路径流式逐日处理，仅保留终值和少量审计路径。固定 Python、依赖、单线程、硬件与输入，预热一次再计时三次，记录中位 wall time、峰值 RSS 和平台。预算目标 fast 在单核 2 分钟内、full 在 8 GB M1 上 30 分钟内、峰值 <1 GiB；首次用 1/10 规模实测外推再确认，以上均待测。云端短生命周期下以配置和汇总重建报告，大型路径与临时输出不入库。

报告应由实验生成数学误差表、MC 收敛图、策略成本/风险图、尾损和归因表、性能基线与测试日志。结果登记规则见[证据台账](RESUME_EVIDENCE.md)。
