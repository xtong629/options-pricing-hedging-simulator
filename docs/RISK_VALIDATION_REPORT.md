## 复现与解释范围

从仓库根目录安装 `python -m pip install ".[dev]"`，执行 `python examples/risk_research.py risk.json`。脚本逐批生成路径，保存每个策略的终值供配对抽样，批大小 512。S=K=100、T=1、r=.03、q=0、μ=.05、定价波动率 .20，每年 252 步，PCG64 路径种子 20261122。

实现提交 58985caf246b59a8e4d568bca1997513493ead17。Linux-6.18.57-x86_64-with-glibc2.41，Python 3.12.14、NumPy 2.5.5、SciPy 1.18.1。单次研究 12.40 秒，进程峰值 RSS 68.18 MiB。详见[研究数据](results/phase4_risk.json)。

VaR 和 ES 描述给定模型的经验损失分布。有限的尾部路径和 bootstrap 次数带来抽样误差，区间为逐项区间。波动率错设、未建模的跳跃、流动性和冲击成本会影响外推。静态结果刻画单次价格变化，动态结果还包含沿路径的交易与融资。
